# Creational Design Pattern Templates

Use these files as student assignments. Each template contains the pattern roles, method signatures, and guiding comments, but the actual object creation logic is intentionally left incomplete.

## Assignment Goal

Implement each creational design pattern without changing the public class name in the file.

Students should:

- Read the comments before writing code.
- Fill every `TODO` section.
- Keep client code dependent on abstractions wherever the pattern expects it.
- Run each `main` method after implementation.
- Compare object identity where the pattern is about controlling instance creation.

## Templates Included

- `FactoryMethodTemplate.java`
- `AbstractFactoryTemplate.java`
- `ClassicBuilderTemplate.java`
- `FluentBuilderTemplate.java`
- `SingletonTemplate.java`
- `PrototypeTemplate.java`

## Suggested Order

1. Factory Method
2. Abstract Factory
3. Builder
4. Fluent Builder
5. Singleton
6. Prototype
